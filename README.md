# Mi Closet Tu Moda 🛍️

**Mi Closet Tu Moda** es una tienda virtual (e-commerce) desarrollada para ofrecer una experiencia de usuario fluida y atractiva. Diseñado con un enfoque en la usabilidad y la presentación del producto, este proyecto fue creado como parte de un trabajo de desarrollo freelance, destacando colecciones de ropa para mujer, hombre y niños, además de accesorios.

## 🚀 Características Principales

*   **Diseño Responsivo:** Interfaz adaptable a múltiples dispositivos (móviles, tablets, escritorio).
*   **Catálogo de Productos:** Navegación estructurada y visualmente atractiva por categorías (Mujer, Hombre, Niños, Accesorios).
*   **Sección de Ofertas y Tendencias:** Exhibición dinámica de productos populares (Más Vendidos) y descuentos de temporada.
*   **Generación de Confianza:** Integración de información sobre beneficios clave como envíos a Colombia, devoluciones, compras seguras y atención directa vía WhatsApp.
*   **Optimización UI/UX:** Uso de carga diferida de imágenes (`loading="lazy"`), transiciones limpias y un diseño centrado en la conversión.

## 🛠️ Tecnologías Utilizadas

*   **Frontend:** HTML5, CSS3, JavaScript.
*   **Tipografía e Íconos:** Google Fonts y librerías de íconos web.
*   **Despliegue / Hosting:** [Netlify](https://www.netlify.com/).

## 💻 Instalación y Uso Local

Para correr este proyecto en tu entorno local, sigue estos pasos:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/AndresCarrillo444/mi-closet-tu-moda.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd mi-closet-tu-moda
   ```
3. Abre el archivo `index.html` en tu navegador web. Para una mejor experiencia de desarrollo, se recomienda usar una extensión como **Live Server** en Visual Studio Code.
